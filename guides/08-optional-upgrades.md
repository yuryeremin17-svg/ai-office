# Опции: платный веб-поиск и экономия на PDF

Базовый офис уже включает бесплатный веб-поиск (DuckDuckGo) и встроенное чтение PDF. Ниже — апгрейды по желанию.

## 1. Качественный веб-поиск (платно)
Бесплатный DuckDuckGo достаточен для базы. Для более точного/свежего поиска — Brave или Tavily.
- Добавить ключ в окружение: `BRAVE_API_KEY` (или `TAVILY_API_KEY`).
- Патч: `{ tools: { web: { search: { provider: "brave" } } } }`
- `openclaw daemon restart`. Движок сам возьмёт ключ.

## 2. Экономия токенов на больших PDF (MarkItDown)
Встроенное чтение PDF уже работает — этот пункт только для оптимизации расхода на КРУПНЫХ текстовых документах.
- MarkItDown (microsoft/markitdown, MIT, локально) вытаскивает чистый текст → в ~5× дешевле, чем «смотреть» страницы.
- Подключать как MCP-сервер (shell-путь недоступен: `exec` в офисе запрещён по безопасности):
```json5
{ mcp: { servers: { markitdown: { command: "uvx", args: ["markitdown-mcp"] } } } }
```
- Нужен Python ≥3.10 на сервере. Инструмент один: `convert_to_markdown`. Держать на STDIO, наружу не открывать.
- Схемы/сканы всё равно читать зрением — MarkItDown берёт только текст.

## Приоритет
Обе опции — не первая необходимость. Базовый офис самодостаточен. Ставить по запросу клиента.
