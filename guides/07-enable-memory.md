# Опция: самопамять (офис сам запоминает контекст)

По умолчанию ВЫКЛЮЧЕНА. Включать только клиенту, который готов к доп. расходу. Решение Юрия 11.07: память = по желанию, не в стандарт.

## Что даёт
- Офис сам копит и вспоминает контекст между разговорами, без команды «запомни».
- Инструмент: claude-mem (thedotmack/claude-mem), лицензия Apache-2.0.

## Приватность (проверено)
- Всё хранится ЛОКАЛЬНО на сервере клиента: база SQLite + локальный поиск, эмбеддинги считаются на месте.
- Наружу для хранения ничего не уходит. Подходит для банк/лизинг/медицина.
- (В отличие от Claude Subconscious/Letta, который слал переписку в чужое облако — тот мы отвергли.)

## Расход — предупредить клиента ОБЯЗАТЕЛЬНО
- Память работает фоновым дожатием → тратит токены на ключе клиента постоянно, не только в диалоге.
- Провайдера сжатия выбрать сознательно при установке — лучше тот же OpenRouter-ключ офиса, не плодить третьих лиц.
- Первые 2-3 недели мониторить расход, потом решать — оставлять ли.

## Как включить
1. Официальный установщик под OpenClaw (ставит воркер на ту же машину):
   `curl -fsSL https://install.cmem.ai/openclaw.sh | bash`
2. Гайд: https://docs.claude-mem.ai/openclaw-integration
3. Воркер держать на localhost, наружу не открывать.
4. Проверить на нашем тестовом сервере ДО установки клиенту — снять реальную цифру расхода.

## Статус
Не обкатано вживую. Ставить только после боевого прогона на тестовом сервере.
