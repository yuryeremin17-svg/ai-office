# Установка на встрече — шпаргалка

> Краткая шпаргалка для установки на встрече: только суть, детали проговариваются голосом.
> Полная версия для самостоятельной установки — `01-install-self.md`.

---

## Перед встречей клиент готовит
- Банковская карта, электронная почта, телефон с Телеграмом.
- ~30 минут спокойного времени, компьютер с браузером.

## Что заведём по ходу
Сервер (DigitalOcean) · Мозг (OpenRouter) · Бот (@BotFather). Платит клиент, напрямую.

---

## Пять шагов

**1. Сервер.** digitalocean.com → Sign up → карта → **Create → Droplets** → Ubuntu 24.04 → план $12 (2 ГБ) → **Password** (записать) → **Create Droplet**.
→ Появился сервер с зелёной точкой и адресом.

**2. Пульт.** Клик по серверу → кнопка **Console** → чёрное окно (логин `root` + пароль).
→ Чёрное окно с курсором. Все команды — сюда.

**3. Скачать офис.** Вставить и Enter:
```
git clone https://github.com/yuryeremin17-svg/ai-office.git /root/office-src
```
→ Побежали строки `Cloning...`, курсор снова пустой.

**4. Сборка + три ключа.** Вставить и Enter:
```
cd /root/office-src && sudo bash install.sh
```
Мастер спросит «Вы в России?» и три ключа:
- **OpenRouter** — openrouter.ai → пополнить $5-10 → Keys → Create Key (`sk-or-...`).
- **Токен бота** — @BotFather → `/newbot` → имя → токен.
- **Ваш Id** — @userinfobot пришлёт число.
→ Зелёные галочки → рамка «Офис готов».

**5. Проверка.** Телеграм → бот → **Start**.
→ Бот ответил. Готово.

---

## Первые минуты (показать клиенту вживую)
- «Запомни: меня зовут … , я руковожу …» — бот запоминает.
- `/model` — эконом / умный. `/new` — чистый лист (дешевле).
- Меню слева от строки ввода — быстрые команды.

## Уход
Обновляется сам каждую ночь. Расход мозга видно на openrouter.ai (Activity), там же лимит.

## 🇷🇺 Если клиент из России
Сервер — не DigitalOcean, а **Timeweb Cloud**, локация **Амстердам/Франкфурт** (оплата рублями/СБП).
Мозг — **DeepSeek** (в мастере ответить «да» на вопрос про Россию), пополнение через Oplatym.ru.
Шаги 2-3-5 — те же. Подробности — в приложении полного гайда.
