# Опция: голос (приём голосовых + ответ голосом)

Включается по желанию клиента. Нужны свои ключи (расход по ним отдельный).

## Что даёт
- Клиент шлёт голосовое в Telegram → офис распознаёт и отвечает.
- Ответ голосом — только когда клиент сам написал голосом (режим `inbound`), чтобы не раздражать.

## Что нужно
- Распознавание речи (STT): ключ Deepgram (`DEEPGRAM_API_KEY`). Дёшево.
- Озвучка (TTS): ключ ElevenLabs (`ELEVENLABS_API_KEY`). Платно по символам.
- Оба встроены в движок — код городить не нужно.

## Как включить
1. Добавить ключи в окружение офиса (в `~/.openclaw/.office-env` или через `openclaw configure`).
2. Патч конфига:
```json5
{
  tools: { media: { audio: { enabled: true, models: [{ provider: "deepgram", model: "nova-3" }] } } },
  messages: { tts: { auto: "inbound", provider: "elevenlabs" } }
}
```
3. `openclaw daemon restart`.

## Предупредить клиента
- STT дешёвое, TTS (озвучка) — основной расход; при активном использовании считать отдельно.
- Только распознавание (без озвучки) — оставить `messages.tts.auto: "off"`, поставить лишь блок audio.
