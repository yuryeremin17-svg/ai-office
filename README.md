# AI-офис для руководителя

Личный AI-ассистент в Telegram, который ставится на ваш собственный сервер за одну команду.
Помнит ваши дела, помогает с задачами и письмами, отвечает круглосуточно. Программировать не нужно.

- **Ваш сервер, ваши данные.** Офис живёт на вашей машине под вашим паролем — не на общем сервисе.
- **Дёшево.** Сервер ~$12/мес + оплата AI по расходу (обычно $2–5/мес). Внезапных счетов нет.
- **Обновляется сам.** Раз в неделю офис тихо обновляется до свежей версии, без вашего участия.

## Установка

На чистом сервере Ubuntu 22.04/24.04 (1 CPU / 2 ГБ) выполните две команды в консоли сервера:

```
git clone <URL-РЕПОЗИТОРИЯ> /root/office-src
cd /root/office-src && sudo bash install.sh
```

Установщик спросит три вещи и всё настроит сам:
- **Ключ OpenRouter** — оплата «мозга» бота (openrouter.ai, пополнить на $5–10).
- **Токен Telegram-бота** — от @BotFather (команда `/newbot`).
- **Ваш Telegram id** — от @userinfobot (замок: бот отвечает только вам).

Через ~15 минут появится «Офис готов» — напишите своему боту `/start`.

> Установщик подтягивает движок **OpenClaw** (`openclaw.ai`) — открытый инструмент, на котором
> работает офис. Всё остальное — в этом репозитории и настраивается прозрачно.

## Что внутри

```
install.sh        — установщик «под ключ» (движок + офис + защита + автообновление)
update.sh         — обновление офиса (движок + навыки, память не трогается)
rollback.sh       — откат на прошлую версию
office-sync.sh    — синхронизация навыков (наше обновляется, ваше остаётся)
heartbeat.sh      — сигнал «жив» на внешний монитор (опционально)
workspace/        — болванка офиса: характер, профиль, память, навыки
```

## Настройка под себя

- Профиль владельца — файл `USER.md`, или прямо в чате: «запомни: меня зовут…».
- Новый навык — папка в `workspace/skills/` с файлом `SKILL.md`.
- Сменить мозг на умный/экономный — команда `/model` в чате бота.
